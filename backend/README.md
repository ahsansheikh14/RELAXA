# Relaxa Backend (Scaffold)

## Run

1. Copy `.env.example` to `.env`
2. Update `MONGODB_URI`
3. Start server:

```bash
npm run dev
```

## Current Status

- Project structure is ready for team development.
- Routes/controllers/models/services exist with placeholders.
- Core server and MongoDB connection are configured.
- Business logic is intentionally not implemented yet.
